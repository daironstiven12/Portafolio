    Perfil

    Quién está detrás del código

    Estudiante de Ingeniería de Telecomunicaciones e Informática, orientado al desarrollo de software, aplicaciones web, backend, bases de datos, inteligencia artificial y UX/UI.

    Combino la formación universitaria con la creación de interfaces y sitios web funcionales. Antes de la universidad obtuve el Tecnólogo en Desarrollo de Software (SENA, 2022), la base sobre la que sigo construyendo proyecto a proyecto.

    Mi forma de trabajar es directa: entender el problema, diseñar la solución, construirla y volver a revisarla. El siguiente tramo de mi camino apunta a React, Node.js y bases de datos para completar el desarrollo full-stack.

    «El aprendizaje es un viaje continuo. Cada proyecto es una oportunidad para mejorar y cada error, una lección.»

    Dairon Orejuela
